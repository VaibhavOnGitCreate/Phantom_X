🛡️ Phantom_X

AI-Powered Cybersecurity Risk Analysis Engine

Phantom_X is an AI-based cybersecurity tool that detects and analyzes phishing messages, suspicious text, and malicious communication patterns using behavioral analysis, OCR, and probabilistic risk modeling.

It converts raw text or screenshots into structured risk scores and visual graphs to help users understand and avoid cyber threats.

🚀 Features

Detects phishing messages and scam content

Generates real-time cybersecurity risk scores

Extracts text from screenshots using OCR

Visualizes threat data using graphs

Provides AI-based threat analysis and insights

Simple web dashboard for easy interaction

🧠 How It Works

User inputs text or captures a screenshot

OCR extracts text (if image used)

AI analyzes threat patterns

Risk datasets are generated

Graphs and threat intelligence are displayed

⚙️ Technology Stack

Python

Flask

Groq API

PyQt5

Pytesseract OCR

Matplotlib / Plotly

HTML, CSS, JavaScript

⚙️ Installation

Clone the repository:

git clone https://github.com/VaibhavOnGitCreate/Phantom_X.git
cd Phantom_X

Install dependencies:

pip install -r requirements.txt

Install Tesseract OCR:

Linux:

sudo apt install tesseract-ocr

Run the application:

python app.py

Open in browser:

http://localhost:5000
